Digdir sin demo-utsteder kan utstede PID, eit fullmaktsbevis og eit dagleg-leiar-bevis. 

Me jobbar med å generalisere denne, slik at den lettare kan hekte seg på andre datakjelder og tilby fleire bevis. 



## Metadata

Du bør finne alt som trengs for å kunne samhandle med utstedere via credential metadata-endepunktet:
